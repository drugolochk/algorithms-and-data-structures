Задание 6. Ориентированный граф.

V = {A, B, C, D, E, F}
E = {(A,B), (A,C), (B,D), (C,D), (C,E), (D,E), (D,F), (E,F)}

Рисунок: sam_6_graf.png


1) Путь из A в F не короче трёх рёбер:

A -> B -> D -> F


2) Повторяющихся вершин в этом пути нет.


3) Путь без циклов существует. Все простые пути A -> F:

A -> B -> D -> F
A -> B -> D -> E -> F
A -> C -> D -> F
A -> C -> D -> E -> F
A -> C -> E -> F

В графе циклов нет (это ациклический орграф), поэтому любой путь без повтора вершин не содержит циклов.
