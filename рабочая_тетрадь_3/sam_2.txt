Задание 2. Максимальный поток из s в t.
Алгоритм Форда–Фалкерсона.

Рисунки: sam_2_graf.png, sam_2_flow.png

Дуги:
S -> A (10),  S -> B (5)
A -> C (8)
C -> D (3),   C -> E (6)
B -> D (6)
D -> F (5),   E -> F (8)
F -> T (10)


Шаг 1. Путь S -> A -> C -> E -> F -> T
min(10, 8, 6, 8, 10) = 6.  Поток = 6.

Шаг 2. Путь S -> A -> C -> D -> F -> T
min(4, 2, 3, 5, 4) = 2.  Поток = 8.

Шаг 3. Путь S -> B -> D -> F -> T
min(5, 6, 3, 2) = 2.  Поток = 10.

Дуга F -> T насыщена, в сток больше ничего не проходит.


Максимальный поток: 10

Минимальный разрез:
S' = {S, A, B, C, D, E, F},  T' = {T}
ребро разреза: F -> T (10)
ёмкость 10
