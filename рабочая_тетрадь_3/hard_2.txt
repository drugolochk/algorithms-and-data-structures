Повышенная 2. Максимальный поток из s в t.
Алгоритм Форда–Фалкерсона.

Рисунки: hard_2_graf.png, hard_2_flow.png

Дуги:
S -> A (9),  S -> B (7)
A -> C (4),  B -> D (6)
C -> E (8),  D -> E (5)
E -> F (7)
F -> G (6)
G -> T (10)


Узкое место всей сети — дуга F -> G ёмкости 6.
Поток не больше 6.

Шаг 1. Путь S -> A -> C -> E -> F -> G -> T
min(9, 4, 8, 7, 6, 10) = 4.  Поток = 4.

Шаг 2. Путь S -> B -> D -> E -> F -> G -> T
min(7, 6, 5, 3, 2, 10) = 2.  Поток = 6.

F -> G насыщена. В T больше ничего не идёт.


Максимальный поток: 6

Минимальный разрез:
S' = {S, A, B, C, D, E, F},  T' = {G, T}
ребро разреза: F -> G (6)
ёмкость 6
