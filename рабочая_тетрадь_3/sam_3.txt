Задание 3. В тексте тетради написано «поток из 1 в 6»,
но на рисунке сеть с вершинами S, A, B, C, D, E, F, T.
Решаем по рисунку: источник S, сток T.
Алгоритм Форда–Фалкерсона.

Рисунки: sam_3_graf.png, sam_3_flow.png

Дуги:
S -> A (12),  S -> B (7)
A -> C (5),   B -> C (3)
C -> E (6),   C -> D (10)
D -> E (5),   D -> F (4)
E -> F (5)
F -> T (7)


В сток ведёт только F -> T ёмкости 7, поэтому поток не больше 7.

Шаг 1. Путь S -> A -> C -> E -> F -> T
min(12, 5, 6, 5, 7) = 5.  Поток = 5.

Шаг 2. Путь S -> B -> C -> D -> F -> T
min(7, 3, 10, 4, 2) = 2.  Поток = 7.

F -> T насыщена. Других путей в T нет.


Максимальный поток: 7

Минимальный разрез:
S' = {S, A, B, C, D, E, F},  T' = {T}
ребро разреза: F -> T (7)
ёмкость 7
