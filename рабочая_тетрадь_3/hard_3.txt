Повышенная 3. Максимальный поток из s в t.
Алгоритм Форда–Фалкерсона.

Рисунки: hard_3_graf.png, hard_3_flow.png

Дуги:
S -> A (10), S -> B (15)
A -> C (10), A -> D (5)
B -> D (10), B -> E (10)
C -> F (10)
D -> F (10), D -> G (5)
E -> G (10), E -> H (5)
F -> I (10)
G -> I (10), G -> J (5)
H -> J (10)
I -> K (15), I -> T (5)
J -> K (10), J -> T (7)
K -> T (10)


В сток T входят только:
I -> T (5),  J -> T (7),  K -> T (10).  Сумма 22.
Значит поток не больше 22.

Шаг 1. S -> B -> E -> H -> J -> T          +5    сумма 5
Шаг 2. S -> B -> E -> G -> I -> T          +5    сумма 10
Шаг 3. S -> B -> D -> G -> J -> T          +2    сумма 12
Шаг 4. S -> B -> D -> F -> I -> K -> T     +3    сумма 15
Шаг 5. S -> A -> C -> F -> I -> K -> T     +7    сумма 22

Все дуги в T насыщены (5+7+10). Других путей нет.


Максимальный поток: 22

Минимальный разрез:
S' = все вершины кроме T,  T' = {T}
рёбра разреза: I -> T (5), J -> T (7), K -> T (10)
ёмкость 22
